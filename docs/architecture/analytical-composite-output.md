# Bounded analytical composite output

The lane carries source-grain meaning through composition, selection, structured
readback and a browser realization. Its authority is the qualified relation and
the judged composition, rather than a chart name or a consumer's reconstruction
of rows. Stage-2 ratification remains open. This does not establish the charter's
M5 text/navigation peers or M6 hostile non-DOM transfer.

## Boundary repair (`REL-COMPOSITE-OUTPUT-01`)

Qualification snapshots field declarations and freezes its own result. Grain
bindings preserve numeric/string identity, compare independently of field order,
and require complete readable bindings. A duplicated complete binding contradicts
uniqueness; an incomplete binding leaves it unproven. Omitted population evidence
is unproven, whereas an explicit empty population has nothing to realize.

Qualified field views consume the snapshot's transformations and units. They
check the target inventory and the same `CAPACITY` table used by atomic programs.
`REL_CHANNEL_TRANSFORMATION_UNSUPPORTED` is a projection-boundary diagnostic,
governed by that table and `readQualifiedPart`; it is not a corpus diagnostic or
a new stage-2 necessity claim. This path establishes cyclic licences only;
proportion/whole declarations remain insufficient for angle admission here.

Composition keeps every transformation requirement on each channel and every
task requirement. A heterogeneous channel has no representative transformation.
Embedding must host every requirement and discharge each carried task at the
cell baseline. A nested magnitude comparison cannot gain ratio comparability
from a truncated position baseline. Free scale profiles dominate shared profiles
when summarizing children. Contradiction dominates missing evidence and absent
support; all fault origins remain in the judgment's part record.

Qualified readback lowering requires a program minted by selection, including
at runtime when a caller casts the TypeScript type. Output is detached from the
frozen qualification. Its mutations cannot change the authority or standing.

The falsifiers are in
[`projection-boundaries.test.ts`](../../packages/ds-codegen/src/analytical/projection-boundaries.test.ts).
They failed against the preceding implementation. Existing composition fixtures
now place ratio values on luminance rather than nominal-only hue, and ratio
endpoints on position rather than ordinal-only order. These repairs establish
boundary behavior; they do not turn a retained judgment into an output carrier.

## Remaining delivery and acceptance

| Obligation | Evidence required |
|---|---|
| A selected composite owns the full admitted values, grain bindings, field facts, view bindings, panels and derived ranges | An unfamiliar nested qualified-view → layer → facet → embed result retains those exact facts after source and request mutation |
| Consumers use selected carried meaning | Lowering accepts only a minted supported selection; rejected, undecided, unsupported and empty paths produce no artifact |
| Structured readback and browser output realize the same selected object | Independent output-only recovery agrees on values, key associations, endpoint/member relationships and panel membership |
| Output checks are sensitive | Value, association, range, panel and standing mutations each change the recovered observation; equal totals cannot mask changed association |
| A visual realization is observable | Playwright inspects actual SVG/DOM geometry and labels under a declared scale; a browser screenshot is inspected |
| Claims stay bounded | Stage-2 specs remain open; no endpoint roles, ordering, aggregation expansion, M5 or M6 acceptance is asserted |

The next slice should introduce a focused carrier/output module instead of
adding another responsibility to `projection.ts`. A browser-safe consumer must
receive the selected artifact without importing the Node-only analytical corpus
loader or independently interpreting source declarations.
